# 黃金行為（每次改動後都要重玩一遍）

> 機器每片跑相關的；多米親手回放在組塊批次驗收時一次做整塊。

## 組塊 A：核心迴圈「接」

### 來自 A1（水管，機器跑；多米在組塊 A 驗收時只看前兩條）
1. 我在 Expo Go 開 douzhang → 應看到 Tokens 底色與字色的畫面，深色模式跟著換。
2. 我跑 `npm test` → 應全綠，測試名稱是中文句子。
3. 壞掉的 JSON 讀不懂時 → 原本的資料還在，不被蓋掉。
4. PWA 舊檔少欄位讀進來 → 補成預設，不崩。
5. 我在 douzhang/ 寫死 `fontSize: 17` 去 commit → 被擋，訊息指出行號。

### 來自 A2（walking skeleton；組塊 A 批次驗時多米親手跑）
6. 我第一次打開，打一句按「開始這顆」 → 進計時中，大時間 25:00 往下數，下面是我那句。
7. 到 0:00 → 畫面自己變鈴響，鍵盤彈起，「收下這顆」貼鍵盤上緣。
8. 鈴響頁打一句按「收下這顆」 → 休息 5:00 倒數 → 按「回來了，開始下一顆」 → 待機正中央是剛寫的那句。
9. 從多工列滑掉再開 → 待機，那句還在。
10. 開發版長按「開始」 → 「測試・1 分」開始一顆，1:00 倒數；正式 build 沒有這個。

### 來自 A3（邊界；組塊 A 批次驗時多米親手跑）
11. 鈴響後拖超過休息長度才收下 → 直接待機，不進休息。
12. 鈴響頁打到一半切走或滑掉再開 → 草稿還在。
13. 鎖屏放過到點再回來 → 一回來就是「響了。」，不閃計時中。

### 來自 A4（通知；組塊 A 批次驗時多米親手跑，真機）
14. 第一次打開寫一句按「開始這顆」 → 這一刻才跳通知對話框；允許或拒絕都進計時中。
15. 開一顆測試顆鎖屏放一分鐘 → 鎖定畫面出現「響了。／寫一行給下一顆的自己。」，沒有我那句；點它進來就是鈴響頁。
16. 收下進休息鎖屏放三分鐘 → 收到「休息完了／回來了，開始下一顆」。
17. 通知被關掉時只有計時中最上面一行「到點通知沒開…」＋「打開通知」；打開後回來那行消失；從頭到尾沒有別的框。

### 來自 A5（鈴響細節）
18. 鈴響頁空白時「收下這顆」是淡的按不下去，下面多一顆「這顆不留話」；按它直接進休息，待機那句沒變。打了字「這顆不留話」消失。
19. 鈴響頁右上「再做 15 分・30 分」→ 半頁選 15 → 回計時中 15:00 倒數；再響一次時右上沒有那個鈕。
20. 拖超過休息長度才回來，鈴響頁副標是「響了 N 分鐘前。收下後直接回待機。」

### 來自 A6（休息細節）
21. 休息時卡片下面有一句（24 句之一），連續兩顆不同句。
22. 設定休息改成「我自己決定」（G1 才有開關）時，休息大時間數正數、不排休息通知、放多久都還在休息，按「回來了」才待機。
