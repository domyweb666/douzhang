# 黃金行為（每次改動後都要重玩一遍）

> 機器每片跑相關的；多米親手回放在組塊批次驗收時一次做整塊。

## 組塊 A：核心迴圈「接」

### 來自 A1（水管，機器跑；多米在組塊 A 驗收時只看前兩條）
1. 我在 Expo Go 開 douzhang → 應看到 Tokens 底色與字色的畫面，深色模式跟著換。
2. 我跑 `npm test` → 應全綠，測試名稱是中文句子。
3. 壞掉的 JSON 讀不懂時 → 原本的資料還在，不被蓋掉。
4. PWA 舊檔少欄位讀進來 → 補成預設，不崩。
5. 我在 douzhang/ 寫死 `fontSize: 17` 去 commit → 被擋，訊息指出行號。

### 來自 A2（walking skeleton；組塊 A 批次驗時多米親手跑）
6. 我第一次打開，打一句按「開始這顆」 → 進計時中，大時間 25:00 往下數，下面是我那句。
7. 到 0:00 → 畫面自己變鈴響，鍵盤彈起，「收下這顆」貼鍵盤上緣。
8. 鈴響頁打一句按「收下這顆」 → 休息 5:00 倒數 → 按「回來了，開始下一顆」 → 待機正中央是剛寫的那句。
9. 從多工列滑掉再開 → 待機，那句還在。
10. 開發版長按「開始」 → 「測試・1 分」開始一顆，1:00 倒數；正式 build 沒有這個。

### 來自 A3（邊界；組塊 A 批次驗時多米親手跑）
11. 鈴響後拖超過休息長度才收下 → 直接待機，不進休息。
12. 鈴響頁打到一半切走或滑掉再開 → 草稿還在。
13. 鎖屏放過到點再回來 → 一回來就是「響了。」，不閃計時中。

### 來自 A4（通知；組塊 A 批次驗時多米親手跑，真機）
14. 第一次打開寫一句按「開始這顆」 → 這一刻才跳通知對話框；允許或拒絕都進計時中。
15. 開一顆測試顆鎖屏放一分鐘 → 鎖定畫面出現「響了。／寫一行給下一顆的自己。」，沒有我那句；點它進來就是鈴響頁。
16. 收下進休息鎖屏放三分鐘 → 收到「休息完了／回來了，開始下一顆」。
17. 通知被關掉時只有計時中最上面一行「到點通知沒開…」＋「打開通知」；打開後回來那行消失；從頭到尾沒有別的框。

### 來自 A5（鈴響細節）
18. 鈴響頁空白時「收下這顆」是淡的按不下去，下面多一顆「這顆不留話」；按它直接進休息，待機那句沒變。打了字「這顆不留話」消失。
19. 鈴響頁右上「再做 15 分・30 分」→ 半頁選 15 → 回計時中 15:00 倒數；再響一次時右上沒有那個鈕。
20. 拖超過休息長度才回來，鈴響頁副標是「響了 N 分鐘前。收下後直接回待機。」

### 來自 A6（休息細節）
21. 休息時卡片下面有一句（24 句之一），連續兩顆不同句。
22. 設定休息改成「我自己決定」（G1 才有開關）時，休息大時間數正數、不排休息通知、放多久都還在休息，按「回來了」才待機。

## 組塊 B：中途保護

### 來自 B1（記一筆）
23. 計時中卡片下有「冒出念頭」「有人找」兩顆 chip → 點「冒出念頭」半頁一行輸入 → 打字按「記下」（或鍵盤 return）→ 回計時中，倒數沒停，chip 變「冒出念頭 1」。
24. 響了之後鈴響頁輸入框下面列著「冒出念頭　那一行」「有人找　那一行」；沒記過就什麼都沒有。

### 來自 B2（結束這顆）
25. 計時中底部是第二顆樣式的「結束」→ 半頁「結束這顆？」：「提早做完了」「作廢這顆」「繼續做」。
26. 按「提早做完了」→ 回計時中，倒數照走，卡片多一行「剩下的時間，唸一遍、檢查、小修。鈴響再停。」；再開「結束」半頁時沒有「提早做完了」。
27. 開始五分鐘後按「作廢這顆」→ 原因半頁四個分段＋一行選填 → 「記一筆」→ 待機，那句沒變，豆子沒多；收據那天多一行「作廢，第 N 分鐘・原因」（E1 看得到）。通知跟著取消（鎖屏不會響）。
28. 開始不到五分鐘按「結束」→ 副標寫「開始不到五分鐘，停下來不會留下紀錄。」，選項叫「停下來」→ 直接待機，什麼都沒記。

## 組塊 C：類型與估幾顆

### 來自 C1
29. 待機點「一般・25 分」→ 半頁「現在做哪一類？」列出類型、選中打勾、最下面「估幾顆・選填，對帳用」。
30. 右上「設定」→ 設定頁「任務類型」：「加一種」多一列「新類型・15 分」；改名、點長度刻度（15／20／25／30／45／50／60）；兩種以上才有「刪除」。回主畫面 chip 與大時間跟著變；殺掉再開還在。
31. 設定頁找不到任何「為這一顆輸入分鐘」的地方。

### 來自 C2
32. 類型半頁點「估幾顆」→ 填名字、點 3 → 「記下來」→ 類型半頁那列變「名字・3 顆」；之後收下的豆掛它（一天的收據「估算對帳」看得到，E1）。
33. 再開估幾顆半頁，下面「今天估過的」列出來可以換，或「不掛任務」。

## 組塊 D：豆罐手感（真機才驗得到）

### 來自 D1
34. 主畫面卡片下方有豆罐區；今天收過的豆子已經躺在罐底（不是從天上掉下來）；50 分那顆是雙豆。
35. 收下這顆 → 回到主畫面約 0.2 秒後一顆豆從罐口掉進來，**落地那一刻**「啵」＋一下較重的震動（不是按下去那一刻）。
36. iPhone 開「減少動態」→ 收下時豆子直接出現在罐底，啵與震動還在；傾斜不滾、點了不彈。
37. 側邊靜音開關撥到靜音 → 啵、嗒都不響，震動還在；設定聲音關掉（G1）同理。

### 來自 D2
38. 傾斜手機豆子往低的那邊滾；設定「傾斜」關掉就不滾。
39. 點罐子附近的豆子被彈起、落回時有「嗒」＋輕震，連續碰撞聲不會糊成一片。
40. 最舊機＋低電量大幅傾斜三秒，掉幀到 40 fps 以下連續三秒 → 自動退成靜止版（不滾不彈），豆子照收。

## 組塊 E：豆棚與收據

### 來自 E1
41. 左上「豆棚」→ 推進頁，左上「回去」；沒有任何豆子時只有一句「第一顆響完，這裡就會掛上今天的豆莢。」＋「回去開始一顆」。
42. 有豆子後：「這週」底下每天一列（N月D日・星期X），右邊一串豆莢：25 分一粒、50 分一粒長的、作廢是空心圈；沒豆子的日子不出現、看不到 0 或紅字。
43. 點一天 → 半頁「N月D日的收據」：由早到晚每顆「HH:MM 那句」，沒留話的顆寫「沒留話」，延長的寫「延長 15 分」，作廢行「作廢，第 N 分鐘・原因：那行」；有估過才有「估算對帳：估 N・實 M」。

### 來自 E2
44. 每週最下一列「翻到背面：這週的收據」→ 半頁：各類型幾格、估少了／估多了／剛好各幾次、一句結論、作廢分佈（達 3 次多一行「作廢多半跟番茄長度…」）、延長提示；數字跟 PWA 同一份資料算出來的一樣（多米拿 PWA 備份比）。
