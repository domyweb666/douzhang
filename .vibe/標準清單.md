# 標準清單（本次任務：片 A4 本地通知）

> 組塊 A 第四片。多米 2026-11-01 指示一路做到 H2 不逐片停，這份只給機器層與最後的批次驗收用。
> 安全標準點名：P1（只申請通知）、P2（被拒不勸、不重複跳框）、P3（通知不含那句）。憲法點名：通知只有「到點」一種、文案固定、每次轉態全部取消再排。

## ✅ 必須做到（可操作測試句）

- [ ] 第一次打開寫一句按「開始這顆」，應該**這一刻**才跳 iOS 的通知對話框（Expo Go 上寫的是 Expo Go 的名字）。允許或拒絕都照常進計時中。
- [ ] 允許通知後，長按開始一顆測試顆，鎖屏放一分鐘，鎖定畫面應該出現通知，標題「響了。」內文「寫一行給下一顆的自己。」**沒有**我寫的那句。點它進 app 直接是鈴響頁。
- [ ] 測試顆響了馬上收下進休息，鎖屏放三分鐘，應該收到一則「休息完了」，內文「回來了，開始下一顆」。
- [ ] 計時中把 app 留在前景等到點，應該只有聲音（或無聲），不跳橫幅，畫面自己變鈴響。
- [ ] 通知被拒（系統設定把豆帳／Expo Go 的通知關掉）再開一顆，計時中畫面最上面一行「到點通知沒開。鈴只在豆帳打開時響。」右邊「打開通知」，按了跳到系統設定。待機、休息、鈴響頁不顯示這一行；**不會再跳任何框**。
- [ ] 在系統設定把通知打開再切回 app，那一行自己消失。
- [ ] 設定聲音關掉（G1 才有開關；這片用程式值）時排的通知沒聲音。
- [ ] 我跑 `npm test`，新的測試是中文句子且全綠，至少有：「計時中排一則到點通知，時刻等於結束時刻，文案固定不含那句」「休息中排一則休息完了」「待機與鈴響頁什麼都不排」「每次同步先全部取消再排」「已允許或被拒且不能再問時不跳框，沒問過才跳」。

## ⛔ 絕對不准做

- 不准動到：`app/`、`index.html`、`.uiux/`（除了詞彙表加三個新詞）、`store.js`、`machine.js` 的既有函式簽名。
- 不准擅自加：橫幅、徽章、重複提醒、「再想想」的勸說框、獎勵、provisional 授權、通知分類與動作按鈕、通知回應監聽器（點通知進 app 後靠 phaseOf 就是鈴響頁，不需要）。
- 不准在通知內文放那句、念頭、有人找的任何字。
- 不准裝新套件（expo-notifications 上個會話已裝）。
- 不准寫死數值、不准 `console.log`。

## 🎯 每條的意圖

- 「第一次按開始才問」是 06 權限時刻表：動作本身已說明為什麼要通知；不在開機問。
- 「不含那句」是安全 P3：鎖定畫面別人看得到。
- 「全部取消再排」是藍圖危險方塊「通知排程」的擋法：排錯或沒取消會在休息時響、作廢後還響。
- 「被拒只顯示一行」是審核指南 5.1.1(iv) 與 P2；那一行只在計時中出現是上個會話的決定（06 寫待機「只顯示一次」，先簡化，帳本記偏離）。
