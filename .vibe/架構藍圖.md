## 白話走讀（多米確認的是這段，不是那張深色圖）

你的 app 是這樣跑的：

1. **打開 app**，先讀手機裡那個 JSON 檔，決定停在哪。沒有那句 → 第一次畫面；有那句、沒在做 → 待機；上次做到一半被殺掉 → 直接回到計時中或鈴響，不會重來。
2. **第一次**：正中央是輸入框，寫完按「開始這顆」，這時 iOS 才跳通知對話框。允許或拒絕都進第一顆，核心不靠權限。
3. **待機**：那句在正中央，底下類型 chip、大時間、豆罐、滿版「開始」。左上豆棚、右上設定。過了收工時間多一個收工入口。
4. **計時中**：記住「結束時刻」，不靠畫面活著；同時排一個到點通知。可以記念頭、記有人找（倒數不停）；按「結束」開半頁三選一：提早做完（繼續倒數）、作廢（只記一筆、取消通知、回待機）、繼續。
5. **到點**：前景自動變鈴響畫面；背景靠通知，點進來就是鈴響畫面。一個輸入框、底下滿版「收下這顆」。右上「再做 15／30」只能用一次，用了回計時中、到點再響。
6. **空白守門**：沒寫字按收下不會收，要另外按「這顆不留話」。
7. **收下**：寫一顆豆進今天、那句換成剛寫的、取消通知、豆子掉進罐（物理只畫，不碰資料）、排休息通知。鈴響後拖太久 → 休息早過了，直接回待機。
8. **休息倒數** → 回待機，那句已經是新的。迴圈閉合。
9. **側線**：豆棚三頁（這週、一天收據、一週收據）只讀資料算收據；收工寫 closed、planted、leaf；設定寫 settings；備份整檔匯出、匯入前先自動備份一份再覆蓋；清空要過系統確認框，回第一次。

## ⚠️ 危險方塊（黑箱驗不全，要特別小心）

| 方塊 | 為什麼危險 | 怎麼擋 |
|---|---|---|
| 備份匯入 | 覆蓋多米的真資料；PWA 舊檔缺欄位 | 匯入前自動備份現有資料；驗 settings 與 days 存在；壞檔不動資料；覆蓋前系統確認框 |
| 清空所有資料 | 不可逆 | 系統確認框；紅字只在設定最底下 |
| 通知排程 | 排錯時間或沒取消 → 休息時響、作廢後還響 | 每次轉態「全部取消再排」，不做差量 |

沒有碰錢、沒有對外連線、沒有別人的資料。

## 🧠 深模組（刪除測試過）

| 模組 | 對外入口 | 背後扛的 | 刪掉會怎樣 |
|---|---|---|---|
| **狀態機＋計時** | 開始、收下、作廢、再做、回來、restore | 結束時刻、背景與鎖屏、殺掉再開、休息過期、再做只一次、每次轉態對通知的排與取消 | 每個畫面各自算時間與排通知，同一個 bug 出現五處。**真深模組，HITL** |
| **資料層＋收據計算＋備份遷移** | load、save、day()、units、週收據、export、import | 格式版本、缺欄位補預設、壞檔不蓋、估 vs 做、作廢分佈、匯入前自動備份 | 收據頁、豆棚、收工各自讀寫 JSON，格式一改全爆。**真深模組，HITL** |
| **豆罐物理** | addBean、tilt、tap | 碰撞、子步、聲音與觸覺節流、減少動態、低電量退路 | 複雜度搬不出去，攤進畫面就沒人看得懂。**真深模組**，但只畫不碰資料，出錯不傷資料 |
| 畫面層（15 畫面） | 各畫面元件 | 只排版、只用 Tokens 與詞彙表 | 淺模組，刻意淺：所有邏輯在上面三塊 |
| 通知 | 排到點、排休息、全部取消 | 權限狀態、點通知導向鈴響 | 介面跟做的事一樣簡單，淺；但被狀態機包住 |

PRD 標的四個深模組都落到圖上了；資料層與備份遷移合併成一塊，因為刪除測試顯示它們共用同一份格式知識。

## 互相獨立的方塊（給 parallel-control 用）

- **豆罐物理** 跟其他全部獨立：輸入只有「加一顆（單或雙）」「傾斜向量」「點」，不讀不寫資料。可以單獨做、單獨換成靜止版。
- **豆棚與收據計算** 只讀資料層，不寫；跟狀態機獨立。
- **設定、收工、備份** 彼此獨立，都只碰資料層。
- **狀態機＋通知** 是一塊，不拆。
- **畫面層**每一個畫面獨立，但都依賴 Tokens 與資料層先在。

依賴順序：資料層 → 狀態機＋通知 → 主畫面四態與鈴響（走通核心迴圈＝walking skeleton）→ 豆罐物理、豆棚、收工、設定、備份（可平行）。

## 技術邊界（寫進圖裡的假設）

- Expo SDK 58、React Native，Expo Go 開發；EAS Build＋TestFlight 正式。
- 單一 JSON 狀態檔在 AsyncStorage，格式同 PWA 原型（v、settings、current、clue、days、planted）。
- expo-notifications 本地排程；expo-sensors 傾斜；expo-haptics；expo-audio；expo-sharing、expo-document-picker、expo-file-system 備份。
- 樣式只從 `.uiux/05-設計代號/Tokens.js`；詞只從詞彙表；數字只從參數表。
- 正式版另起資料夾（名字由 decompose 定），不從 `app/` 長出來。
