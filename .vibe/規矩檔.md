# 規矩檔（AI 每次動工前必讀）

## 通用 AI 行為基準（從專案第一天起就成立，勿改）

1. **不准猜假設，不確定就問。** 收到任何指令，若有不明確的詞、有多種可能的解讀、缺少關鍵資訊——**停下來把不明確的地方列出來問使用者**，不要替他選一個解讀就動手。靜默的假設是這套系統最大的失敗源頭。

2. **每一行改動都必須能追溯到使用者的明確要求。** 不准順手「改進」相鄰的程式碼、不准重整不相干的格式、不准刪掉「看起來像死碼」但不在這次任務範圍內的東西、不准做沒被要求的重構。每一行 diff 都要對得上一句使用者講過的話。

3. **不准加沒被要求的功能、抽象、設定項、錯誤處理。** 「想說以後可能會用到」「順便寫得更彈性一點」「加個 config 比較好」——全部不准。要做的事跟使用者要的事一對一，多的一律砍。

## AI 憲法（vibe-voice-lock 2026-11-01 焊入；格式與可驗證規則由 .vibe/hooks/pre-commit.sh 強制，不在此重複）

### 0. 前提
- 格式不用管，Prettier／ESLint 處理。不要為排版花任何推理。
- 寫任何檔前先讀 `douzhang/` 裡最像的那個檔，模仿它的結構；沒有就讀 `.vibe/切片帳本.md` 這片的說明，不要自帶一套。

### 1. 架構邊界（douzhang/）
- 固定四層，不准多：`design/`（Tokens.js、params.js、words.js，只放代號與數字）、`core/`（store.js、machine.js、notify.js、receipt.js，純邏輯，不 import react-native 畫面元件）、`screens/`（一個畫面一個檔）、`ui/`（跨畫面共用的小元件）。
- `core/` 不准 import `screens/`、`ui/`；`screens/` 之間不准互相 import，共用的東西往 `ui/` 或 `core/` 放。
- 不准引入 Repository／Service／Manager／Provider 多層包裝、不准引入狀態管理庫（Redux、Zustand、MobX）、不准 RxJS、不准 Expo Router。狀態用 `useState`／`useReducer`＋一個 context 就夠。
- 不准新加任何 npm 套件，除非切片帳本那片寫了名字；加了要走 `npx expo install`。

### 2. 反過度工程禁令（每條都是可判定動作）
- 不准為「未來可能會用到」加參數、抽象層、config 開關、feature flag。
- 新功能預設寫成一個函式。要拆檔、拆 hook、抽共用元件前先停下來問。
- 只有一個實作時不准抽 interface、不准依賴注入。
- 不准寫 class 元件；不准 HOC；不准自己寫 event emitter。
- 不准加沒被要求的錯誤處理、重試、快取、節流，除了安全標準 S3、S6、I1、I3 點名的那幾個。

### 3. 豆帳專屬（可驗證的部分 hook 會擋，這裡寫為什麼）
- 顏色、字級、間距、圓角、動畫時長只准來自 `design/Tokens.js` 與 `design/params.js`。畫面檔出現 `#RRGGBB`、`rgba(`、`fontSize: 17` 就是錯，hook 會擋；真的例外寫 `// token-ok: 原因` 並在 `.uiux/lessons.md` 記一筆。
- 介面上每一個字只准來自 `design/words.js`（翻自 `.uiux/05-設計代號/詞彙表-暫定.md`）。要新詞先加進詞彙表再加進 words.js。
- 元件一律放模組層級，不准在元件函式裡定義另一個元件（2026-10-31 踩過：計時 re-render 重掛）。
- 計時只存 `endAt`，不存「剩幾秒」；畫面用時間差算。
- 通知只有「到點」一種，文案固定，不含那句話；每次轉態「全部取消再排」。
- 匯入前先自動備份；壞檔不動資料；不裝第三方分析、崩潰回報、廣告、WebView（hook 擋 import）。
- 不准出現連續天數、「你今天還沒開始」、紅字催促、「0 顆」這類字（產品定稿「最怕變成罪惡感 app」）。

### 4. 可讀性四條
- 命名要表達意圖：`endAt`、`restMinutes`、`unsavedDraft`，不是 `t`、`m`、`tmp`。
- 註解只寫「為什麼」：當下的取捨、踩過的雷、不得不的妥協。做什麼程式碼自己說。
- 不留魔術數字：`180` 要叫 `params.beanDrop.delayMs`；`86400000` 要叫 `MS_PER_DAY`。
- 最小驚訝：函式不准偷做名字沒說的事。`loadState()` 不准順手寫檔；`keepBean()` 不准順手改設定。

### 5. 不確定時
- 選最無聊、最少程式碼、最像鄰近檔案的那個做法，然後問多米。

- 2026-11-01：想在電腦上預覽 RN 畫面要裝 react-dom、react-native-web，這兩個不在片的白名單就不准裝；要用先寫進切片帳本那片的套件清單。
- 2026-11-01：外部資料（匯入、舊檔）要驗到「會進算術的那一欄」（例如每顆的 len），只驗外層是物件不夠，units() 會算成 NaN。
