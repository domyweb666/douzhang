# 操作清單・待驗（豆罐手感原型，2026-10-31）

> 這是 VibeRails 的過手單：AI 寫完，**你親手在 iPhone 上跑**，每條回「過／不過＋看到什麼」。沒過手之前不算做完。
> 電腦 web 模式只驗過：畫面出現、調整面板開得起來、滑桿有、掉豆計數會加。物理順不順、聲音、觸覺、傾斜，web 全驗不了。

## 怎麼開
1. Expo Go 更新到最新 → 電腦 `cd E:\豆帳\app` 跑 `npx expo start` → 手機掃 QR。
2. 右上角淡字母 → 除錯頁 → 最下面「豆罐手感原型」。

## 一、它有沒有活著（先看這五條）
| # | 做 | 應該看到 | 過／不過 |
|---|---|---|---|
| 1 | 進頁面 | 5 顆灰豆已經躺在罐底（不是從天上掉下來）；上方寫「今天 5 顆豆・xx fps・傾斜中・1 號」 | |
| 2 | 看 fps | 穩定接近 60（120Hz 機型可能顯示 120 或 60） | |
| 3 | 傾斜手機 | 豆子往低的那邊滾。**往上飛**→ 長按標題開面板，打開「反轉傾斜方向」，記下來告訴我 | |
| 4 | 點罐子 | 附近的豆子被彈起、落下；落回時有「嗒」聲和輕震 | |
| 5 | 按「收下這顆」 | 約 0.2 秒後一顆豆從上方掉進來，**落地那一刻**同時有「啵」聲＋一下較重的震動（不是按下去那一刻） | |

## 二、參數表要的量測（寫回 .uiux/04-手感/手感測試紀錄-暫定.md）
| # | 做 | 記什麼 |
|---|---|---|
| 6 | 另一支手機開 240fps 慢動作，拍你的手指點罐子 | 手指碰到那格 → 最近的豆開始動那格，差幾格（×4 ms） |
| 7 | 面板按「40 顆」，開低電量模式，大幅傾斜 3 秒 | fps 掉到多少、哪個動作卡；觸覺還有沒有出來 |
| 8 | 面板切「2 號參數組」（牆面恢復 0.3 → 0.45），自己不要判斷，找人盲測 | 各玩一分鐘後想多玩哪個 |
| 9 | 把手機交給一個人只說「你可以玩玩看」 | 10 秒內有沒有反應、玩多久放下、放下後有沒有再拿起 |

## 三、規矩檔對照（你不用懂程式，看行為就好）
| 要求來源 | 怎麼看 |
|---|---|
| 參數表：數字不寫死 | 面板每條滑桿動了畫面就跟著變，「全部回到參數表初值」能還原 |
| 2-4 第 7 條：減少動態 | iPhone 設定 → 輔助使用 → 動態效果 → 減少動態 開啟，回 app：豆子不滾不彈，收下時豆子直接出現在罐底，「啵」還在 |
| 2-4 第 7 條：靜音 | 側邊靜音開關撥到靜音，「啵」「嗒」都不該響，震動還在 |
| 2-7：互動區離邊緣 | 從罐底往上滑幾次，不該跳回主畫面 |
