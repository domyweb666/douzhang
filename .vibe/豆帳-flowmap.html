正常路徑 失敗／退路 回頭（再做一下） 條件分支 寫資料／排通知 紫框＝🧠深模組 橘框＝⚠️危險方塊 虛線框＝尚未對應檔案
🤖 給 Claude Code 的讀圖說明 
這份 HTML 包含一個 <script id="flowmap-data" type="application/json"> 區塊。
讀取方式：document.getElementById('flowmap-data').textContent，然後 JSON.parse()。

重要欄位：
- nodes[].trigger_condition：這個狀態的觸發條件
- nodes[].file_responsibilities：每個檔案在此節點的具體職責（待掛點版全部為空；health-check／integrate 重跑掛點模式時補）
- nodes[].planned_module：藍圖階段預計由哪個模組負責（給 decompose 切片用，不是真實檔名）
- nodes[].flags：deep（深模組）、warn（危險方塊）
- file_index：反查表，給你一個檔名，告訴你它出現在哪些節點
- edges[].type：success / failure / retry / conditional / data，代表分支語意

當你修改一個檔案時，先查 file_index 找到它涉及的所有節點，
再看每個節點的 edges 確認你的修改是否影響到下游分支。
