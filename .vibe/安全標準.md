# 安全標準（這個專案的自查表）

> 由 `vibe-security-gate` 階段 A 建立（2026-11-01）。
> 1. 給 AI 看：之後寫任何一片，寫完先過這份清單。
> 2. 給多米看：上線前對著它逐項自查（階段 C）。
>
> **這不是合格證書，是自查表。** 豆帳不碰錢、不碰別人的資料、不連網，風險面很窄；但備份匯入會覆蓋多米自己的真資料，那是這個 app 唯一會「弄丟東西」的地方。

---

## 這個專案的類型

**已確認類型**：Mobile App（iPhone，Expo／React Native）。多米 2026-11-01 確認。

**判定證據**：
- `app/package.json` 含 `expo ~58`、`react-native 0.88`，一串 `expo-*` 套件；有 `app.json`。
- 根目錄 `index.html`＋`manifest.webmanifest` 是舊 PWA 原型，只做考古，正式版不是網頁 → 不套網頁標準。
- 沒有後端、沒有 API、沒有 LLM 套件、沒有金流。

**資料面**：單一 JSON 在 AsyncStorage，內容是多米自己的工作紀錄（每顆的時間、那句話、作廢原因、估幾顆）。沒有密碼、token、金鑰、個資欄位。

---

## 適用的權威標準

- ✅ OWASP MASVS（手機 app）：只有 STORAGE、PLATFORM、CODE、PRIVACY 四組適用。
- ✅ CWE Top 25（通用兜底）：只有輸入驗證、路徑、反序列化三條適用。
- ❌ MASVS-NETWORK、MASVS-AUTH、MASVS-CRYPTO、MASVS-RESILIENCE：不適用，原因在下面逐條寫，階段 C 要重新確認「仍然不適用」（例如之後加了 iCloud 就不是）。

## 必查清單

### 一、本機儲存與備份（MASVS-STORAGE）

| # | 檢查項 | 被打中會怎樣 | 豆帳怎麼做 |
|---|---|---|---|
| S1 | 狀態檔裡**沒有**任何機敏欄位（密碼、token、金鑰、電話、email） | 手機被拿走或備份檔外流，連帶洩漏 | 資料模型只有 PRD 列的欄位；加新欄位先對 PRD |
| S2 | 因為 S1 成立，AsyncStorage 明文存**可以接受**；不裝加密層 | — | 階段 C 若發現多了機敏欄位，S2 立刻翻成「要 Keychain」 |
| S3 | 匯入前**自動把現有資料備份一份**到 app 沙盒（`FileSystem.documentDirectory`），檔名帶時間 | 匯錯檔把三個月的豆子蓋掉，回不來 | 備份片的必過行為；設定頁要能看到「上次自動備份」 |
| S4 | 覆蓋前跑系統確認框，文案「用備份覆蓋現在的資料？」 | 誤觸 | 用 `Alert.alert`，不自己畫 |
| S5 | 清空所有資料：系統確認框，文案寫清楚不可逆 | 誤觸 | 同上；紅字只在設定最底下 |
| S6 | 寫檔失敗要被看到（AsyncStorage 配額、磁碟滿） | 以為存了其實沒有，隔天那句不見 | 寫失敗顯示一行「這台裝置沒辦法存，記得匯出備份」（原型已有） |
| S7 | 匯出檔不放進 app 自己的公開目錄；走系統分享選單讓多米決定去哪 | 檔案留在奇怪的地方 | `expo-sharing`，分享完就不留副本（自動備份的除外） |
| S8 | 不把資料印到 console／log | 除錯 log 進到裝置日誌 | 正式版不留 `console.log` 整包狀態 |
| S9 | 退到背景時不需遮蔽畫面 | — | 內容不機敏，**不做**（規矩檔第 3 條） |

### 二、輸入驗證（CWE-20、CWE-502、CWE-22）

| # | 檢查項 | 被打中會怎樣 | 豆帳怎麼做 |
|---|---|---|---|
| I1 | 匯入的 JSON 先 `JSON.parse` 包 try，再驗 `settings` 與 `days` 存在、`v` 是數字 | 壞檔讓 app 當掉或寫進半套資料 | 驗不過只顯示「這個檔案讀不懂」，**資料不動** |
| I2 | 匯入的每一天、每一顆用「缺欄位補預設」讀，不信任外部欄位型別 | PWA 舊檔少 `restOver`、`leaf` → 收據算爆 | 走資料層的 `normalize()`，不讓畫面直接讀匯入物件 |
| I3 | 匯入檔大小上限（例如 5 MB），超過拒絕 | 幾百 MB 的檔把記憶體吃光 | 讀檔前看 `FileSystem.getInfoAsync().size` |
| I4 | 不對匯入內容跑 `eval`、`new Function`、動態 require | 檔案裡夾程式碼就被執行 | 只 `JSON.parse` |
| I5 | 檔名由 app 自己產（`豆帳備份-YYYY-MM-DD.json`），不拿使用者輸入組路徑 | 路徑穿越 | 匯出不接受自訂檔名 |
| I6 | 使用者打的字（那句、念頭、原因、類型名）只當字串存與顯示，不進任何模板或指令 | — | RN `Text` 本身不解 HTML，沒有 XSS 面；仍不做字串拼 shell／SQL（本專案沒有） |
| I7 | 字數上限：那句 120 字、類型名 20 字（跟原型一致） | 超長字把收據版面撐爆 | `maxLength`，不另跳錯誤框 |

### 三、平台與隱私（MASVS-PLATFORM、MASVS-PRIVACY）

| # | 檢查項 | 被打中會怎樣 | 豆帳怎麼做 |
|---|---|---|---|
| P1 | （2026-11-17 AG6 補：白噪音開了背景音訊模式 `UIBackgroundModes: audio`，這不是權限、不會跳框；沒有用 expo-audio 的設定外掛，所以沒有麥克風用途說明。送審要說明背景音訊的用途。）只申請兩種權限：**通知**、**螢幕使用時間**（2026-11-17 AF1 加；只有打開「計時中擋住其他 app」或點「要擋的 app」才問，沒開這功能的人不會被問）；加速度計 iOS 不需授權 | 審核退件、使用者不信任 | 權限時刻表見 `.uiux/06`；`app.json` 不宣告用不到的 usage description；螢幕使用時間用自己寫的原生模組（`douzhang/modules/app-shield/`），沒裝第三方套件、沒有擴充、沒有 App Group；選了哪些 app 是系統給的不透明代號，只存本機、讀不出名稱、不進備份 |
| P2 | 通知權限被拒後不勸、不重複跳框、不給獎勵 | 違反審核指南 5.1.1(iv) | 只顯示一行＋「打開通知」去系統設定 |
| P3 | 通知內容不含那句話的全文（鎖定畫面別人看得到） | 旁人看到工作內容 | 通知文案固定「響了。寫一行給下一顆的自己。」 |
| P4 | App Store 隱私標示填「不蒐集資料」，且要是真的：**不裝任何第三方分析、崩潰回報、廣告 SDK** | 標示與實際不符被下架 | 埋點只在本機計數（3-8），不上傳 |
| P5 | 「刪除我的資料」＝設定頁「清空所有資料」，要真的清乾淨（含自動備份檔） | 殘留 | 清空時一併刪 `documentDirectory` 下的自動備份 |
| P6 | Deep link、URL scheme：第一版**不註冊**自訂 scheme | 外部 app 可觸發內部狀態 | `app.json` 不設 `scheme`（Expo Go 開發期的 exp:// 不算） |
| P7 | 沒有 WebView | — | 不引入 `react-native-webview` |

## 不適用（寫下原因，階段 C 要重新確認）

| 組 | 為什麼不適用 | 什麼時候會變適用 |
|---|---|---|
| MASVS-NETWORK（HTTPS、憑證綁定） | 完全離線，沒有任何網路請求 | 加 iCloud、加同步、加任何 API |
| MASVS-AUTH（登入、token） | 沒有帳號 | 加帳號 |
| MASVS-CRYPTO（加密演算法、金鑰） | 沒有機敏資料、沒有加密需求 | S1 失守時 |
| MASVS-RESILIENCE（反逆向、越獄偵測） | 個人工具，沒有可被偷的邏輯或資產 | 加付費內容 |
| CWE-79／352（XSS、CSRF）、CWE-89（SQL）、CWE-78（shell） | 沒瀏覽器、沒 SQL、沒 shell | 加 WebView、加 SQLite 原生查詢 |
