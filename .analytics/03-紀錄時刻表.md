## 紀錄時刻表

### 記一筆（念頭、有人找）

| 欄 | 內容 |
|---|---|
| 觸發事件 | 計時中她自己點畫面，或下面那顆「記一筆」圓鈕（2026-11-24 QC-0003 起；原本在「⋯」裡），或聚焦模式的「記一筆」。app 不會自己跳出來 |
| 出現在哪 | 原本的記一筆半頁。鎖定畫面上不能記（之後有即時動態再談） |
| 問句 | 標題「記一筆」。小字「點一下就記下。想寫一行也可以，休息時再處理。」 |
| 選項 | 「冒出念頭」→ `notes` 多一筆｜「有人找」→ `pings` 多一筆 |
| 預設 | **不預選**（現在預選念頭，要拿掉）。理由：字變選填之後，預選的那個會直接變成答案，念頭的次數會被灌水 |
| 跳過 | 不點任何一個、下滑關掉＝沒記，什麼都不存 |
| 時間預算 | 2 下、兩秒內（點畫面、點種類）。現在是 2 到 3 下再加打字 |
| 選填的那一行 | 點完種類後輸入框才出現，提示字照舊：「冒出什麼念頭？」／「誰找你、什麼事？」。不寫就關掉；寫了按「記下」 |
| 答完之後 | 半頁收起，計時畫面不多任何東西（計時中不加字）。好處在鈴響頁兌現：這顆記過的東西列在那裡，休息時處理。沒寫字的合成一行「有人找 2 次」，不列空行 |

為什麼這樣寫：

- 兩個選項都在說發生了什麼事，沒有一個在說她 ✅（現有的字就是這樣）。
- 書把「被打斷但沒停下的計數」列在不做，理由是計時中多點一下也是成本。番茄帳本來就有這個功能，而且是她自己點的，不是 app 問的；行為目標 2（留）靠的就是這一下，所以留著，但要做到最省力。
- 點錯種類怎麼辦：選填那一行出現的同時，上面兩個種類還在，點另一個就是改，不會記成兩筆。這個細節放進比較頁一起看。

**版面多米 11-22 看比較頁選了 B**：沿用現在的分段鈕，不預選。程式已寫（AI13）。選填那一行不自己拿游標，要寫才點。

### 作廢原因、選填那一行

| 欄 | 內容 |
|---|---|
| 觸發事件 | 開始五分鐘之後，「結束這顆？」裡按「作廢這顆」。不到五分鐘叫「停下來」，不問、不記（定案） |
| 出現在哪 | 作廢原因半頁，確認跟回答同一張 ✅ |
| 問句 | 標題「作廢這顆」。沒有小字（原本「原因寫事實就好。」，2026-11-24 AI17 拿掉） |
| 選項 | 「念頭」→ `念頭`｜「有人找」→ `有人找`（舊資料的 `訊息` 讀的時候當同一種）｜「卡住」→ `卡住`｜「其他」→ `其他` |
| 預設 | 不預選 ✅ |
| 跳過 | 不選直接按確認，存空字串（未填）✅。之後不補問 ✅ |
| 時間預算 | 2 下（選原因、確認）；不選是 1 下 |
| 選填那一行 | 提示字「例：去看留言（分鐘數會自動記）」，不用改 |
| 答完之後 | 回到待機，開始鈕上方一行，停到她按開始或離開這頁：「這週第 2 顆因為有人找作廢。」沒選原因就不出現 |

為什麼這樣寫：

- 「作廢」這個詞留著。書提醒按鈕不要叫「放棄」，因為那是在說人；「作廢」的主詞是這顆番茄，而且小字已經寫明「只記一筆，不扣任何東西」。
- 答完之後那一行只有次數，不接「要不要開擋 app」這種建議。建議要過門檻、而且要她自己點進細查層才看得到（3-5、3-6 再定）。
- 原因四個的順序固定，不隨機。

### 收下時寫的那一句

| 問句 | 提示字「這顆做了什麼、下次從哪接」 |
| 選項 | 自由打字 |
| 預設 | 空的 |
| 跳過 | 不點就是跳過，直接收下，存空字串 ✅ |
| 時間預算 | 不寫是 0 下 |
| 答完之後 | 收下後寫進這顆的收據 |

書說「做完的那一刻不問」。這裡沒有違反：它不擋收下、不是問題、不點就看不到輸入框。不用改。

## ❓ 多米的決定（2026-11-22：兩條都照建議改）

### ❓1 作廢原因的「訊息」要不要改叫「有人找」→ 改（A）

現況：計時中記一筆叫「有人找」，作廢原因叫「訊息」。同一件事兩個名字。Q3 要把這兩邊加在一起講（「這週有人找 5 次：3 次記一筆之後繼續、2 顆作廢」），名字不統一這句寫不出來。而且同事走過來拍肩膀不算「訊息」，她會猶豫要選訊息還是其他。

| 做法 | 代價 |
|---|---|
| A. 畫面改叫「有人找」（建議） | 舊資料裡存的是「訊息」兩個字。讀的時候把「訊息」「有人找」當同一種，不改舊資料。收據上舊的那幾筆也顯示成「有人找」 |
| B. 維持「訊息」 | Q3 的句子要分開講兩邊；面對面被打斷的會落到「其他」 |

### ❓2 作廢半頁的確認鈕現在叫「記一筆」→ 改成「作廢這顆」

跟計時中的「記一筆」同名，按下去卻是作廢這顆。建議改成「作廢這顆」（跟標題一樣，按鈕名動詞帶對象）。這是改一個字串，不動版面。

## 不問的時刻

| 時刻 | 為什麼 |
|---|---|
| 計時中 | app 不主動問任何事。記一筆是她自己點才出現 |
| 鈴響那一刻 | 那是收下的時刻。寫一句是選填，不擋收下 |
| 打開 app | 第一個畫面只有開始 |
| 斷了一陣子回來的第一顆 | 同上，不先填東西 |
| 不到五分鐘的停下來 | 定案不問、不記 |
| 事後補問 | 沒選原因的作廢，之後不會再問（收據上也不放「補一下原因」） |
| 同一件事問第二次 | 跳過了就是跳過了 |

## 這一版不做的

- 鎖定畫面、動態島上直接記一筆：現在沒有即時動態。之後做的時候，兩個種類直接做成按鈕。
- 記一筆的時刻：不存（`02` 不收清單）。
- 作廢時把記一筆的種類自動帶成原因：會變成預選，不做。
