## 怎麼跑到 iPhone 上
1. iPhone 裝 App Store 的 Expo Go，**更新到最新**（專案是 SDK 58，舊版 Expo Go 會拒開；開專案時出現「SDK 不符」就告訴我，我降版）。
2. 電腦：
```bash
cd E:\豆帳\app
npx expo start
```
3. 手機跟電腦同一個 Wi-Fi，用 iPhone 相機掃終端機的 QR code，Expo Go 會開。
4. 改程式會即時重載。

## 裡面有什麼
- **三個方向**：右上角小字母（A／B／C）點開除錯頁切換。同一個人測三個方向就在這裡切。
- **四態**：待機 → 開始 → 計時中 → 到點自動進鈴響 → 收下 → 休息 → 回待機。試玩速度預設開（1 分＝1 秒），所以 25 分 25 秒就響。
- **第一次**：除錯頁「重設為第一次」，待機變成寫第一件事。
- **鈴響**：真的鍵盤、真的鍵盤避讓。A 收下鈕貼鍵盤上方；B 收下鈕在輸入框正下；C 圓鈕＋鍵盤「完成」送出。空白時才出現「這顆不留話」。
- **再做 15／30 分**：一顆只出現一次。
- **計時中**：冒出念頭／有人找（半頁，一行輸入）、結束（半頁：提早做完／作廢／繼續做）。
- **豆棚、設定**：全頁佔位（清單用系統字排），只為了測「第一下點哪裡」與最大字級，內容不是真的。
- **豆罐**：靜態灰圓，點了沒反應。重力、傾斜、彈跳是 feel（3-4）的事，不在線框做。
- **虛線＝點擊範圍**，除錯頁可關，拍截圖給人看時關掉。

## 單手檢查表要在這上面補的四項
| 項 | 怎麼做 |
|---|---|
| 鍵盤 | 鈴響頁、第一次頁、記一筆、收工：鍵盤升起時要按的東西有沒有被蓋 |
| 最大字級 | iPhone 設定 → 輔助使用 → 顯示與文字大小 → 更大的文字 → 拉到最右。回 app 看每一態每個方向，除錯頁「塞 120 字那句」「40 豆」一起開 |
| 系統邊緣 | 手指從豆罐底往上拖幾次，會不會跳回主畫面；A 的開始鈕按十次有沒有一次滑到手勢區 |
| 大小手機 | 手邊最大與最小的 iPhone 各裝一次，除錯頁會顯示螢幕 pt 與字級倍率，抄進檢查表 |

結果寫回 `單手檢查表-暫定.md`，把「待真機」逐格改成過／不過＋怎麼改。
