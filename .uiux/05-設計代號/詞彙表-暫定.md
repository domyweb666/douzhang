# 詞彙表（v0.1 暫定）

> 規則：畫面上的字只能用這張表裡的名字。名字由多米定，Agent 只撈出全 app 現有說法、標出同物多名。來源欄：「使用者測試」要等樹狀測試與方向測試帶回使用者自己的叫法，現在全是「暫定（原型）」。
> 按鈕名一律動詞帶對象（「收下這顆」「作廢這顆」，不用「確定」「好」）。

| 東西或動作 | 定下來的名字（暫定） | 拿掉的說法（原型裡出現過） | 來源 |
|---|---|---|---|
| 一段 25 分鐘的專注 | 一顆 | 番茄、一段、focus | 暫定（原型） |
| 做完一顆留下的那句話 | 下一步 | 線索、clue、那句、第一句 | 暫定；流程把「畫面就是線索」改掉了 |
| 開始一顆的動作 | 開始 | — | 暫定 |
| 到點 | 響了 | 鈴響、到點、bell | 暫定（鈴響頁標題用「響了。」） |
| 到點後留下那句並結束這顆 | 收下這顆 | 收、記下、完成 | 暫定 |
| 不寫下一步就收 | 這顆不留話 | 畫面就是線索（已拿掉） | 暫定（流程 ❓ 定案） |
| 到點後再延 15／30 分 | 再做 15 分／再做 30 分 | 在狀態裡再做一下、flow、延長 | 暫定（標題句可保留「在狀態裡，再做一下」當說明） |
| 計時中記一件事以後處理 | 記一筆 | 冒出念頭、有人找、quickNote、便條 | **同物多名**：原型兩個入口「冒出念頭」「有人找」是「記一筆」的兩種；多米定要不要合成一個 |
| 中途結束，不算一顆 | 作廢這顆 | 停下來、結束、void、放棄 | 暫定；「停下來」只用在不到五分鐘不留紀錄的情況，多米定要不要分 |
| 中途做完，剩餘時間留著 | 提早做完了 | done | 暫定 |
| 收下後的短暫停 | 休息 | rest、喝水時間 | 暫定 |
| 今天收到的全部 | 今天的豆子 | 豆罐、jar | 暫定；「豆罐」只用在原型與設計檔，不上畫面 |
| 每一顆在畫面上的樣子 | 豆子 | 豆、pea、顆 | 暫定 |
| 50 分那一顆 | 雙豆 | x2、兩格、two | 暫定 |
| 一天的豆子串起來 | 豆莢 | pod | 暫定 |
| 看過去日子的地方 | 豆棚 | 其他功能、rack、紀錄 | 暫定；**樹狀測試重點**，使用者叫它什麼就改什麼 |
| 一天的明細 | 這天的收據 | receipt、明細、紀錄 | 暫定；「收據」是隱喻，待測 |
| 一週的統計 | 這週的收據 | 翻到背面、週報 | 暫定；「翻到背面」是入口文案，待測會不會讓人退回 |
| 事前估這件事幾顆 | 估幾顆 | 估算、est、任務 | 暫定 |
| 估與實際的比較 | 估算對帳 | 對帳、準不準 | 暫定 |
| 整天開會沒番茄的日子 | 掛一片葉子 | 不算缺、leaf | 暫定 |
| 一天結束的動作 | 收工 | 結束今天、close | 暫定 |
| 計時長度的分類 | 任務類型 | 類型、type、模式 | 暫定；設定頁用「任務類型」，待機 chip 只顯示名字與分鐘 |
| 鈴只在打開時響的狀態 | 到點通知沒開 | 權限被拒、notification denied | 暫定；文案要寫「怎麼開」，不寫「錯誤」 |
| 清除全部 | 清空所有資料 | 重設、wipe | 暫定；唯一不可逆，確認框標題寫後果 |

## 語氣規則
- 畫面上的字只能用詞彙表裡的名字。
- 可愛的話只能由「收下後那 24 句」說；錢、錯誤、權限、備份用平實語氣，第一句先回答有沒有損失（例：「這個檔案讀不懂，原本的資料沒動」）。
- 系統訊息不用驚嘆號、不用「哦」「喔」；角色句（24 句）可以。
